# Contributing

Thanks for your interest in contributing to BasicMails! This file explains how to contribute, file issues, and submit pull requests.

## Getting Started
1. Fork the repo.
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes and include tests where applicable.
4. Run linters and tests: `npm install && npm test && npm run lint`.
5. Commit and push your branch, then open a PR.

## PR Guidelines
- Give PRs a clear title and description.
- Reference relevant issues.
- Keep changes focused; one feature/fix per PR when possible.
- Add or update tests for new behavior.
- Ensure lint and type checks pass.

## Code Style
- TypeScript + ESLint + Prettier conventions apply.
- Run `npm run format` before committing.
